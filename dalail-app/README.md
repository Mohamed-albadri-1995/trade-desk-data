# دلائل الرحمات — تطبيق أندرويد

قارئ نصّ أصلي للكتاب: النصّ مكتوب حرفًا بحرف، لا صورًا، فيُكبَّر ويُصغَّر
ويُفتَح على آخر صفحة وقفت عندها، ويعمل بلا إنترنت.

## من أين يأتي النصّ

النصّ المنسوخ يعيش في مجلد `dalail/` في جذر المستودع — ملفّ لكل صلاة. وملفّ
التطبيق `app/src/main/assets/dalail.txt` **مُولَّد** منه، فلا يُحرَّر بيده. بعد
أي تعديل على النصّ:

```
python3 tools/dalail_asset.py
```

وبذلك يبقى للنصّ مصدرٌ واحد يخدم الكتاب المطبوع (`tools/dalail_book.py`)
والتطبيق معًا.

## العلامات في ملفّ النصّ

| العلامة | معناها |
|---|---|
| `= …` | اسم الكتاب |
| `# …` | قسم — مقدمة، حزب، دعوة الصلوات. ويبدأ صفحةً جديدة عليها الشريط المزخرف |
| `## ٧` + تبويب + السور | رقم الصلاة، وبعده السور التي بُنِيَت عليها (تظهر في الفهرس لا في الصفحة) |
| `~ …` | خاتمة الكتاب، في أسفل آخر صفحة |
| `⟨…⟩` | عدد التكرار — يُكتب بخط مائل ذهبي، فهو خطاب للقارئ لا من الدعاء |
| `﴿…﴾` | قرآن أو اسم سورة — بلون الكتاب الفيروزي |
| `♡` | فاصلة الكتاب بين دعوة وأخرى — تُرسم زهرةً ذهبية |

## البناء

يُبنى تلقائيًّا عند كل دفعٍ إلى الفرع، ويُنشَر ملفّ `app-debug.apk` في
[إصدار `dalail-latest`](../../releases/tag/dalail-latest). انظر
`.github/workflows/build-dalail.yml`.

وللبناء بيدك: افتح مجلد `dalail-app` في Android Studio، ثم **Build → Build
APK(s)**.
